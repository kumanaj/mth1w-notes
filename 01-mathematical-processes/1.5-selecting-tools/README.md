# 1.5 Focus on Selecting Tools and Computational Strategies

> 📖 Textbook pp. 23–28 · [⬅ Chapter 1](../)

## Big idea
Choose the **right tool** for the job: mental math, pencil and paper, calculator, grid paper,
physical models (tiles, cubes), or a computer. Sometimes you need more than one.

## Vocabulary
| Term | Meaning |
|------|---------|
| **pentomino** | a shape made of five unit squares, each sharing at least one full side with another |
| **rational number** | a number that can be written as $\frac{a}{b}$ where $a, b$ are integers and $b \ne 0$, e.g. $-\frac{3}{5}$, $0.25$, $1\frac{3}{4}$, $-3$ |

## Key concepts
- The best tool is the one that is **fastest and accurate enough**:
  - $10 + 20$ → mental math, not a calculator
  - length of a soccer field → trundle wheel, not a 30-cm ruler
- **Rational numbers** combine your fraction skills with your integer skills.
  - Add/subtract: common denominator, then add numerators using integer rules.
  - Subtracting = adding the opposite.
  - Multiply/divide: same as fractions; the sign follows the integer rules.
- **Don't round in the middle** of a calculation. Use fraction keys or keep full decimals.

## Worked examples

### Example 1: Adding and subtracting rational numbers
$$\text{a) } \frac{3}{8} + \left(-\frac{1}{8}\right) = \frac{3 + (-1)}{8} = \frac{2}{8} = \frac{1}{4}$$

$$\text{b) } \frac{1}{2} + \frac{2}{3} = \frac{3}{6} + \frac{4}{6} = \frac{7}{6} = 1\frac{1}{6}$$

$$\text{c) } \frac{3}{5} - \frac{1}{4} = \frac{3}{5} + \left(-\frac{1}{4}\right) = \frac{12}{20} + \left(-\frac{5}{20}\right) = \frac{7}{20}$$

### Example 2: Multiplying and dividing rational numbers
$$\left(-\frac{3}{4}\right) \times \frac{1}{5} = -\frac{3}{20} \qquad \left(-\frac{2}{3}\right) \div \left(-\frac{4}{5}\right) = \left(-\frac{2}{3}\right) \times \left(-\frac{5}{4}\right) = \frac{10}{12} = \frac{5}{6}$$

### Example 3: Ted's calculator error
Ted evaluated $\frac{5}{9} + \frac{2}{3} - \frac{1}{8}$ as $0.6 + 0.7 - 0.1 = 1.2$.
He **rounded too early**. Exact:
$\frac{40}{72} + \frac{48}{72} - \frac{9}{72} = \frac{79}{72} \approx 1.097$.
Use the fraction key, or keep all digits until the end.

### Example 4: Sums of cubes (pattern tool)
$1^3 = 1,\; 1^3 + 2^3 = 9,\; 1^3 + 2^3 + 3^3 = 36,\; \ldots$ These are perfect squares:
$1^2, 3^2, 6^2, \ldots$, i.e. $(1 + 2 + \cdots + n)^2$.
So the first 15 cubes sum to $(1 + 2 + \cdots + 15)^2 = 120^2 = 14\,400$.

## Watch out
- ⚠️ Division by zero is **undefined**: $12 \div 0$ has no answer.
- ⚠️ A calculator only helps if you key in the order of operations correctly. Use brackets.

## Quick check
1. $\frac{1}{2} + \left(-\frac{3}{4}\right)$
2. $-\frac{1}{4} - \frac{1}{6}$
3. $\frac{5}{6} \times \left(-\frac{3}{10}\right)$
4. Find the 1000th term of $45, 41, 37, 33, \ldots$

<details><summary>Answers</summary>

1. $\frac{2}{4} - \frac{3}{4} = -\frac{1}{4}$
2. $-\frac{3}{12} - \frac{2}{12} = -\frac{5}{12}$
3. $-\frac{15}{60} = -\frac{1}{4}$
4. Term $n = 45 - 4(n - 1)$, so term 1000 $= 45 - 4(999) = -3951$.

</details>
