## Curriculum expectations

- **B1.1**: research a number concept to tell a story about its development and use in a specific culture, and describe its relevance in a current context
- **B1.2**: describe how various subsets of a number system are defined, and describe similarities and differences between these subsets
- **B1.3**: use patterns and number relationships to explain density, infinity, and limit as they relate to number sets

## Key ideas to learn

- [ ] Know the number sets and how each is defined: natural $\mathbb{N}$, whole $\mathbb{W}$, integers $\mathbb{Z}$, rational $\mathbb{Q}$, irrational $\overline{\mathbb{Q}}$, real $\mathbb{R}$
- [ ] Show how the sets nest inside each other: $\mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$
- [ ] Irrational numbers have decimals that never end or repeat: $\sqrt{2}$, $\pi$
- [ ] **Density:** between any two rational numbers there is always another one (e.g. their mean)
- [ ] **Infinity:** every number set except a finite list goes on forever
- [ ] **Limit:** values can get closer and closer to a number without reaching it, e.g. $\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \ldots \to 0$
- [ ] Research task (B1.1): the story of a number concept in a specific culture, e.g. zero in Mayan or Indian mathematics
