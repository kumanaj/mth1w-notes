# Rates, Percentages, and Proportions

> 📘 **Curriculum:** B3.5 · 📖 **Textbook:** Get Ready p. 41 (rates only) · [⬅ Strand B: Number](../)

> 📝 **Outline only. This topic is not in the textbook.** It is part of MTH1W, so you'll need class notes or another resource. Use [the section template](../../templates/section-template.md) when writing notes.

## Curriculum expectations

- **B3.5**: pose and solve problems involving rates, percentages, and proportions in various contexts, including contexts connected to real-life applications of data, measurement, geometry, linear relations, and financial literacy

## Key ideas to learn

- [ ] **Unit rate:** $\frac{348 \text{ km}}{4.0 \text{ h}} = 87 \text{ km/h}$. Compare best buys with unit prices
- [ ] **Percent:** percent of a number, percent increase/decrease, and discounts and taxes (13% HST in Ontario)
- [ ] **Proportions:** solve $\frac{a}{b} = \frac{c}{d}$ by equivalent ratios or cross-multiplying
- [ ] Apply these to scale drawings, recipes, maps, speed and money
