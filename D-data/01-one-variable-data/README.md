# Data in the Real World and One-Variable Data

> 📘 **Curriculum:** D1.1, D1.2 · 📖 **Textbook:** not covered · [⬅ Strand D: Data](../)

> 📝 **Outline only. This topic is not in the textbook.** It is part of MTH1W, so you'll need class notes or another resource. Use [the section template](../../templates/section-template.md) when writing notes.

## Curriculum expectations

- **D1.1**: identify a current context involving a large amount of data, and describe potential implications and consequences of its collection, storage, representation, and use
- **D1.2**: represent and statistically analyse data from a real-life situation involving a single variable in various ways, including the use of quartile values and box plots

## Key ideas to learn

- [ ] D1.1: big-data contexts (social media, health, sports analytics). Think about privacy, storage, and how the way data is shown can mislead
- [ ] Types of one-variable data: categorical vs. numerical (discrete or continuous)
- [ ] Measures of central tendency: **mean, median, mode**; spread: **range**
- [ ] **Quartiles:** $Q_1$, $Q_2$ (median), $Q_3$; interquartile range $IQR = Q_3 - Q_1$
- [ ] **Box plots** (five-number summary: min, $Q_1$, median, $Q_3$, max) and histograms
- [ ] Choose the best display and statistic for a data set, and spot outliers
