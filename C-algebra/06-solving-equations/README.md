## Key ideas to learn

- [ ] Use inverse operations to isolate the variable; keep the equation balanced
- [ ] Solve multi-step equations with brackets and variables on both sides
- [ ] Clear fractions by multiplying by the lowest common denominator
- [ ] Rearrange formulas (e.g. solve $P = 2l + 2w$ for $w$)
- [ ] Write an equation from a word problem, solve it, and **verify** by substituting
