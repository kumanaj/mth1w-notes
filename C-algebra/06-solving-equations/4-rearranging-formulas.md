# Lesson 4: Rearranging Formulas

> 📖 Textbook §4.4, pp. 211–219 · [⬅ Solving Equations](README.md)

## Big idea
A **formula** is an equation with several letters. To "solve for" one letter, use the **same
opposite operations** as before and treat the other letters as if they were numbers.

## The two-step method
1. **Isolate the term** that contains the variable you want (add or subtract).
2. **Isolate the variable** (multiply, divide, or take the square root).

> 💡 **Stuck?** Solve a version with numbers first, then copy the same steps with letters.
> Example: $10 = 2x + 4$ → subtract 4, then divide by 2. So $y = mx + b$ → subtract $b$, then divide by $m$.

## Worked examples

### Example 1: One step
| Formula | Solve for | Step | Result |
|---------|-----------|------|--------|
| $d = a + b$ (exterior angle) | $a$ | subtract $b$ | $a = d - b$ |
| $C = 2\pi r$ (circumference) | $r$ | divide by $2\pi$ | $r = \dfrac{C}{2\pi}$ |
| $v = \dfrac{d}{t}$ (speed) | $d$ | multiply by $t$ | $d = vt$ |
| $A = l^2$ (square) | $l$ | square root | $l = \sqrt{A}$ |

### Example 2: Two steps
Solve $y = mx + b$ for $x$.
$$
\begin{aligned}
y &= mx + b \\
y - b &= mx && \text{step 1: subtract } b \text{ to isolate the } x\text{-term}\\
\frac{y - b}{m} &= x && \text{step 2: divide by } m
\end{aligned}
$$

### Example 3: Brackets
Solve $P = 2(l + w)$ for $l$.
$$
\begin{aligned}
P &= 2(l + w) \\
\frac{P}{2} &= l + w && \text{divide by 2}\\
\frac{P}{2} - w &= l && \text{subtract } w
\end{aligned}
$$

### Example 4: Substitute first or rearrange first?
*A square has area 32 cm². How long is each side?*

- **Substitute first:** $32 = l^2 \Rightarrow l = \sqrt{32} \approx 5.7$ cm
- **Rearrange first:** $l = \sqrt{A}$, then $l = \sqrt{32} \approx 5.7$ cm

Both work. Rearranging first gives a new formula you can **reuse** for any area.

### Example 5: Temperature conversion
Solve $C = \frac{5}{9}(F - 32)$ for $F$.
$$
\begin{aligned}
C &= \tfrac{5}{9}(F - 32) \\
\tfrac{9}{5}C &= F - 32 && \text{multiply by the reciprocal } \tfrac{9}{5}\\
\tfrac{9}{5}C + 32 &= F && \text{add 32}
\end{aligned}
$$
Check: water boils at $C = 100$, and $\frac{9}{5}(100) + 32 = 180 + 32 = 212$ °F ✓

## Watch out
- ⚠️ Undo adding/subtracting **before** multiplying/dividing: from $y = mx + b$, subtracting $b$ comes first.
- ⚠️ When you divide, divide the **whole side**: $\frac{y - b}{m}$, not $y - \frac{b}{m}$.
- ⚠️ Square root is the opposite of squaring. Use it only when the variable is squared.

## Quick check
Rearrange each formula for the variable shown.
1. $A = lw$, for $w$
2. $I = Prt$, for $r$ (simple interest)
3. $P = 2l + 2w$, for $w$
4. $A = \pi r^2$, for $r$
5. Use your answer to question 4 to find the radius of a circle with area 50 cm², to one decimal place.

<details><summary>Answers</summary>

1. $w = \dfrac{A}{l}$
2. $r = \dfrac{I}{Pt}$
3. $P - 2l = 2w$, so $w = \dfrac{P - 2l}{2}$
4. $r^2 = \dfrac{A}{\pi}$, so $r = \sqrt{\dfrac{A}{\pi}}$
5. $r = \sqrt{\dfrac{50}{\pi}} \approx \sqrt{15.92} \approx 4.0$ cm

</details>
