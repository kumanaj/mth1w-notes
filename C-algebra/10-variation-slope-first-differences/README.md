## Key ideas to learn

- [ ] **Direct variation** $y = kx$ passes through the origin; **partial variation** $y = mx + b$ has an initial value $b$
- [ ] Slope $m = \dfrac{\text{rise}}{\text{run}} = \dfrac{y_2 - y_1}{x_2 - x_1}$
- [ ] Slope as a **rate of change** (e.g. km/h, dollars per item)
- [ ] **Constant first differences** in a table → linear relation
- [ ] Connect the table, graph, equation and concrete model: the rate of change is the slope, and the initial value is the $y$-intercept
