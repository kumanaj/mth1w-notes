# The Distributive Property

> 📘 **Curriculum:** C1.4 · 📖 **Textbook:** §3.7, pp. 160–169 · [⬅ Strand C: Algebra](../)

## Big idea
A term in front of brackets multiplies **every** term inside, like handing one copy of a
handout to each student.
$$a(x + y) = ax + ay$$

## Vocabulary
| Term | Meaning |
|------|---------|
| **distributive property** | $a(x + y) = ax + ay$; multiplying a sum by a number is the same as multiplying each term by it and adding |
| **expand** | remove brackets by multiplying |

## Key concepts
- **Area model:** a rectangle of width $a$ and length $x + y$ has area $a(x + y)$, which is the sum of two smaller rectangles $ax + ay$.

```
        x        y
     +--------+-----+
  a  |   ax   |  ay |
     +--------+-----+
```

- When distributing a monomial:
  1. Multiply the **coefficients**.
  2. Apply the **exponent laws** to the variables ($x \cdot x = x^2$).
  3. Watch the **signs**: a negative in front changes the sign of every term inside.
- **Expand and simplify** = distribute, then collect like terms.
- You need the distributive property when the terms inside the brackets **aren't like terms**: $3(x + 5)$ can't become $3(5x)$.

## Worked examples

### Example 1: Apply the distributive property
$$3(x + 5) = 3x + 15$$
$$-2(3x - 4) = -6x + 8$$
$$4(2x^2 - 3x + 1) = 8x^2 - 12x + 4$$

### Example 2: Distribute variables
$$3x(x + 2) = 3x^2 + 6x$$
$$-2k(k^2 - 5k + 3) = -2k^3 + 10k^2 - 6k$$

### Example 3: Expand and simplify
$$
\begin{aligned}
2(x + 3) - 3(x - 1) &= 2x + 6 - 3x + 3\\
&= -x + 9
\end{aligned}
$$

$$
\begin{aligned}
x(x + 4) + 2x(3x - 1) &= x^2 + 4x + 6x^2 - 2x\\
&= 7x^2 + 2x
\end{aligned}
$$

### Example 4: Area with algebra tiles
A rectangle is $x$ wide and $x + 3$ long: area $= x(x + 3) = x^2 + 3x$
(one $x^2$-tile and three $x$-tiles).

## Watch out
- ⚠️ Dmitri wrote $3x(x + 2) = 3x + 2x$. Wrong: he forgot to multiply. Correct: $3x^2 + 6x$.
- ⚠️ $-3(x - 1) = -3x + 3$, not $-3x - 3$, because a negative times a negative is positive.
- ⚠️ Multiply **every** term inside, including the last constant.

## Quick check
Expand and simplify.
1. $5(2y - 3)$
2. $-x(4x - 7)$
3. $3(a + 2) + 2(a - 5)$
4. $4m(m - 2) - m(3m + 1)$
