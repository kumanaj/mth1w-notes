# Glossary (Chapters 1–3)

> A–Z vocabulary from the notes. The section where each word is introduced is linked.
> The textbook glossary is on pp. 582–591. · [⬅ Course home](README.md)

| Term | Definition | Section |
|------|------------|---------|
| **algebraic expression** | a mathematical phrase made up of numbers and variables connected by addition or subtraction, e.g. $2x + 3$ | [3.1](03-polynomials/3.1-algebraic-models/) |
| **base** | the identical factor in a power; in $2^4$ the base is 2 | [3.2](03-polynomials/3.2-exponents/) |
| **bias** | error resulting from choosing a sample that does not represent the whole population | [2.2](02-relations/2.2-sampling-principles/) |
| **binomial** | a polynomial with two terms, e.g. $x + 4$ | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **census** | a survey of all members of a population | [2.2](02-relations/2.2-sampling-principles/) |
| **coefficient** | the numerical factor of a term; in $4x^2$ it is 4 | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **conjecture** | a general conclusion drawn from a number of individual facts; it may or may not be true | [1.6](01-mathematical-processes/1.6-reasoning-and-proving/) |
| **counter-example** | an example that proves a conjecture is false | [1.6](01-mathematical-processes/1.6-reasoning-and-proving/) |
| **curve of best fit** | a curve that comes closest to the points on a scatter plot of a non-linear relation | [2.5](02-relations/2.5-linear-and-non-linear-relations/) |
| **degree of a polynomial** | the degree of the highest-degree term | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **degree of a term** | the sum of the exponents on the variables in a term | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **dependent variable** | a variable that is affected by some other variable; plotted on the vertical axis | [2.3](02-relations/2.3-scatter-plots/) |
| **distance-time graph** | a graph that shows how distance varies with time | [2.6](02-relations/2.6-distance-time-graphs/) |
| **distributive property** | $a(x + y) = ax + ay$ | [3.7](03-polynomials/3.7-distributive-property/) |
| **exponent** | the number of identical factors in a power; in $2^4$ the exponent is 4 | [3.2](03-polynomials/3.2-exponents/) |
| **extrapolate** | estimate a value beyond the range of a set of data | [2.4](02-relations/2.4-trends-interpolation-extrapolation/) |
| **hypothesis** | a theory or statement that is either true or false | [2.1](02-relations/2.1-hypotheses-and-data-sources/) |
| **independent variable** | a variable that affects the value of another variable; plotted on the horizontal axis | [2.3](02-relations/2.3-scatter-plots/) |
| **inference** | a conclusion based on reasoning and data | [2.3](02-relations/2.3-scatter-plots/) |
| **interpolate** | estimate a value between two measurements in a set of data | [2.4](02-relations/2.4-trends-interpolation-extrapolation/) |
| **like terms** | terms that have identical variables (with the same exponents) | [3.5](03-polynomials/3.5-collect-like-terms/) |
| **line of best fit** | a straight line that comes closest to the points on a scatter plot | [2.5](02-relations/2.5-linear-and-non-linear-relations/) |
| **linear relation** | a relation between two variables that forms a straight line when graphed | [2.5](02-relations/2.5-linear-and-non-linear-relations/) |
| **mean** | the sum of the values in a set of data divided by the number of values | [1.6](01-mathematical-processes/1.6-reasoning-and-proving/) |
| **monomial** | a polynomial with one term, e.g. $-5ab^2$ | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **natural number** | a number in the sequence $1, 2, 3, 4, \ldots$ | [1.1](01-mathematical-processes/1.1-problem-solving/) |
| **non-random sampling** | using a method that is not random to choose a sample from a population | [2.2](02-relations/2.2-sampling-principles/) |
| **outlier** | a measurement that differs significantly from the rest of the data | [2.3](02-relations/2.3-scatter-plots/) |
| **pentomino** | a shape made of five unit squares, each sharing at least one side with another | [1.5](01-mathematical-processes/1.5-selecting-tools/) |
| **perfect square** | a number that can be expressed as the product of two identical factors, e.g. $36 = 6 \times 6$ | [1.1](01-mathematical-processes/1.1-problem-solving/) |
| **polynomial** | an algebraic expression of one or more terms connected by addition or subtraction | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **population** | the whole group of people or items being studied | [2.2](02-relations/2.2-sampling-principles/) |
| **power** | a product of identical factors, written as a base and an exponent, e.g. $2^4$ | [3.2](03-polynomials/3.2-exponents/) |
| **prime number** | a number with exactly two factors, itself and 1 | [1.1](01-mathematical-processes/1.1-problem-solving/) |
| **primary data** | original data that a researcher gathers specifically for a particular experiment or survey | [2.1](02-relations/2.1-hypotheses-and-data-sources/) |
| **random sample** | a sample in which all members of a population have an equal chance of being chosen | [2.2](02-relations/2.2-sampling-principles/) |
| **rational number** | a number that can be expressed as the quotient of two integers, where the divisor is not zero | [1.5](01-mathematical-processes/1.5-selecting-tools/) |
| **sample** | any group of people or items selected from a population | [2.2](02-relations/2.2-sampling-principles/) |
| **secondary data** | data that someone else has already gathered for some other purpose | [2.1](02-relations/2.1-hypotheses-and-data-sources/) |
| **simple random sampling** | choosing a specific number of members randomly from the entire population | [2.2](02-relations/2.2-sampling-principles/) |
| **statistics** | numerical data, or the collection, organization and analysis of numerical data | [2.1](02-relations/2.1-hypotheses-and-data-sources/) |
| **stratified random sampling** | dividing a population into distinct groups and then choosing the same fraction of members from each group | [2.2](02-relations/2.2-sampling-principles/) |
| **systematic random sampling** | choosing members of a population at fixed intervals from a randomly selected member | [2.2](02-relations/2.2-sampling-principles/) |
| **term** | an expression formed by the product of numbers and/or variables, e.g. $4x^2$ | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **trinomial** | a polynomial with three terms, e.g. $x^2 + 3x - 1$ | [3.4](03-polynomials/3.4-communicate-with-algebra/) |
| **variable** | a quantity whose value can change, usually represented by a letter | [3.1](03-polynomials/3.1-algebraic-models/) |
| **vertex** (pl. vertices) | a point at which two sides meet | [1.4](01-mathematical-processes/1.4-representing/) |
