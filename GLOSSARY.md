# Glossary

> A–Z vocabulary from the notes, linked to the topic where each word is introduced.
> The textbook glossary is on pp. 582–591. · [⬅ Course home](README.md)

| Term | Definition | Topic |
|------|------------|---------|
| **algebraic expression** | a mathematical phrase made up of numbers and variables connected by addition or subtraction, e.g. $2x + 3$ | [Algebraic Models With Tiles](C-algebra/01-algebraic-models/) |
| **base** | the identical factor in a power; in $2^4$ the base is 2 | [Powers and Exponents](B-number/02-powers/) |
| **bias** | error resulting from choosing a sample that does not represent the whole population | [Sampling Principles](D-data/05-sampling/) |
| **binomial** | a polynomial with two terms, e.g. $x + 4$ | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **census** | a survey of all members of a population | [Sampling Principles](D-data/05-sampling/) |
| **coefficient** | the numerical factor of a term; in $4x^2$ it is 4 | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **conjecture** | a general conclusion drawn from a number of individual facts; it may or may not be true | [Reasoning and Proving](A-mathematical-thinking/06-reasoning-and-proving/) |
| **counter-example** | an example that proves a conjecture is false | [Reasoning and Proving](A-mathematical-thinking/06-reasoning-and-proving/) |
| **correlation** | how strongly two variables are related on a scatter plot: positive, negative or none; strong or weak | [Scatter Plots and Correlation](D-data/02-scatter-plots/) |
| **curve of best fit** | a curve that comes closest to the points on a scatter plot of a non-linear relation | [Linear and Non-Linear Relations](C-algebra/08-linear-and-non-linear-relations/) |
| **degree of a polynomial** | the degree of the highest-degree term | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **degree of a term** | the sum of the exponents on the variables in a term | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **dependent variable** | a variable that is affected by some other variable; plotted on the vertical axis | [Scatter Plots and Correlation](D-data/02-scatter-plots/) |
| **distance-time graph** | a graph that shows how distance varies with time | [Distance-Time Graphs](C-algebra/09-distance-time-graphs/) |
| **distributive property** | $a(x + y) = ax + ay$ | [The Distributive Property](C-algebra/05-distributive-property/) |
| **exponent** | the number of identical factors in a power; in $2^4$ the exponent is 4 | [Powers and Exponents](B-number/02-powers/) |
| **extrapolate** | estimate a value beyond the range of a set of data | [Trends, Interpolation, and Extrapolation](D-data/03-trends-interpolation-extrapolation/) |
| **hypothesis** | a theory or statement that is either true or false | [Hypotheses and Sources of Data](D-data/04-hypotheses-and-data-sources/) |
| **independent variable** | a variable that affects the value of another variable; plotted on the horizontal axis | [Scatter Plots and Correlation](D-data/02-scatter-plots/) |
| **inference** | a conclusion based on reasoning and data | [Scatter Plots and Correlation](D-data/02-scatter-plots/) |
| **integer** | a positive or negative whole number, or zero | [Rational Numbers](B-number/04-rational-numbers/) |
| **interpolate** | estimate a value between two measurements in a set of data | [Trends, Interpolation, and Extrapolation](D-data/03-trends-interpolation-extrapolation/) |
| **like terms** | terms that have identical variables (with the same exponents) | [Collect Like Terms](C-algebra/03-like-terms/) |
| **line of best fit** | a straight line that comes closest to the points on a scatter plot | [Linear and Non-Linear Relations](C-algebra/08-linear-and-non-linear-relations/) |
| **linear relation** | a relation between two variables that forms a straight line when graphed | [Linear and Non-Linear Relations](C-algebra/08-linear-and-non-linear-relations/) |
| **mean** | the sum of the values in a set of data divided by the number of values | [Reasoning and Proving](A-mathematical-thinking/06-reasoning-and-proving/) |
| **monomial** | a polynomial with one term, e.g. $-5ab^2$ | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **natural number** | a number in the sequence $1, 2, 3, 4, \ldots$ | [Problem Solving](A-mathematical-thinking/01-problem-solving/) |
| **non-random sampling** | using a method that is not random to choose a sample from a population | [Sampling Principles](D-data/05-sampling/) |
| **outlier** | a measurement that differs significantly from the rest of the data | [Scatter Plots and Correlation](D-data/02-scatter-plots/) |
| **pentomino** | a shape made of five unit squares, each sharing at least one side with another | [Selecting Tools and Computational Strategies](A-mathematical-thinking/05-selecting-tools/) |
| **perfect square** | a number that can be expressed as the product of two identical factors, e.g. $36 = 6 \times 6$ | [Problem Solving](A-mathematical-thinking/01-problem-solving/) |
| **polynomial** | an algebraic expression of one or more terms connected by addition or subtraction | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **population** | the whole group of people or items being studied | [Sampling Principles](D-data/05-sampling/) |
| **power** | a product of identical factors, written as a base and an exponent, e.g. $2^4$ | [Powers and Exponents](B-number/02-powers/) |
| **prime number** | a number with exactly two factors, itself and 1 | [Problem Solving](A-mathematical-thinking/01-problem-solving/) |
| **primary data** | original data that a researcher gathers specifically for a particular experiment or survey | [Hypotheses and Sources of Data](D-data/04-hypotheses-and-data-sources/) |
| **random sample** | a sample in which all members of a population have an equal chance of being chosen | [Sampling Principles](D-data/05-sampling/) |
| **rational number** | a number that can be expressed as the quotient of two integers, where the divisor is not zero | [Rational Numbers](B-number/04-rational-numbers/) |
| **reciprocal** | the number you multiply by to get 1; the reciprocal of $\frac{6}{7}$ is $\frac{7}{6}$ | [Rational Numbers](B-number/04-rational-numbers/) |
| **sample** | any group of people or items selected from a population | [Sampling Principles](D-data/05-sampling/) |
| **secondary data** | data that someone else has already gathered for some other purpose | [Hypotheses and Sources of Data](D-data/04-hypotheses-and-data-sources/) |
| **simple random sampling** | choosing a specific number of members randomly from the entire population | [Sampling Principles](D-data/05-sampling/) |
| **statistics** | numerical data, or the collection, organization and analysis of numerical data | [Hypotheses and Sources of Data](D-data/04-hypotheses-and-data-sources/) |
| **stratified random sampling** | dividing a population into distinct groups and then choosing the same fraction of members from each group | [Sampling Principles](D-data/05-sampling/) |
| **systematic random sampling** | choosing members of a population at fixed intervals from a randomly selected member | [Sampling Principles](D-data/05-sampling/) |
| **term** | an expression formed by the product of numbers and/or variables, e.g. $4x^2$ | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **trinomial** | a polynomial with three terms, e.g. $x^2 + 3x - 1$ | [Terms and Polynomials](C-algebra/02-terms-and-polynomials/) |
| **unit fraction** | a fraction with numerator 1, e.g. $\frac{1}{4}$ | [Rational Numbers](B-number/04-rational-numbers/) |
| **variable** | a quantity whose value can change, usually represented by a letter | [Algebraic Models With Tiles](C-algebra/01-algebraic-models/) |
| **vertex** (pl. vertices) | a point at which two sides meet | [Representing](A-mathematical-thinking/04-representing/) |
