# MTH1W: Grade 9 Math Study Notes

My study notes for **MTH1W** (Ontario Grade 9 Mathematics, de-streamed), organized by the strands of the
[official Ontario curriculum](https://www.dcp.edu.gov.on.ca/en/curriculum/secondary-mathematics/courses/mth1w).
Textbook references are to *Principles of Mathematics 9* (McGraw-Hill Ryerson).

> **Why strands and not textbook chapters?** The curriculum is organized into strands A–F, not units.
> Each school decides its own unit order, and the textbook was written for the older MPM1D course.
> These notes follow the curriculum's strands, and [TEXTBOOK-MAP.md](TEXTBOOK-MAP.md) shows where each
> textbook chapter fits so you can still read along in the book.

## How these notes are organized

```
mth1w-notes/
├── README.md                     ← you are here
├── TEXTBOOK-MAP.md               ← textbook chapter/section → curriculum strand/topic
├── GLOSSARY.md                   ← every vocabulary word, A–Z
├── A-mathematical-thinking/
│   ├── README.md                 ← strand overview: expectations, topic list, checklist
│   ├── 01-problem-solving/
│   │   └── README.md             ← notes for one topic
│   └── ...
├── B-number/  C-algebra/  D-data/  E-geometry-and-measurement/  F-financial-literacy/
└── templates/section-template.md
```

Every topic page starts with its **curriculum codes** (e.g. B2.1) and **textbook pages**, then:
big idea → vocabulary → key concepts → worked examples → watch out → quick check (answers hidden).

## Study tips
- Read the topic note **before** the textbook section, then do the textbook's Practise questions.
- Try the **Quick check** without peeking, then open the answers.
- Before a test, go through the strand README's **review checklist**.
- Math is written in LaTeX (`$x^2$`), which renders on GitHub and in VS Code's Markdown preview.
