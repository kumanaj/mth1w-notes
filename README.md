# MTH1W — Grade 9 Math Study Notes

My study notes for **MTH1W** (Ontario Grade 9 Mathematics), following the textbook
*Principles of Mathematics 9* (McGraw-Hill Ryerson). Page numbers refer to that book.

> The textbook was written before the de-streamed MTH1W course, so a few topics are
> ordered differently from the current curriculum, but the math is the same.

## How these notes are organized

```
mth1w-notes/
├── README.md                  ← you are here (course table of contents)
├── GLOSSARY.md                ← every vocabulary word, A–Z
├── 01-mathematical-processes/
│   ├── README.md              ← chapter overview, vocabulary, review checklist
│   ├── 1.1-problem-solving/
│   │   └── README.md          ← notes for one section
│   └── ...
├── 02-relations/
├── 03-polynomials/
├── 04-… 09-…                  ← planned chapters (outline only for now)
└── templates/section-template.md
```

Every section note uses the same layout:

1. **Big idea**: the one-sentence takeaway
2. **Vocabulary**: definitions to memorize
3. **Key concepts**: rules, formulas and methods
4. **Worked examples**: step-by-step solutions
5. **Watch out**: common mistakes
6. **Quick check**: practice questions, with answers hidden in a drop-down

## Study tips
- Read the section note **before** the textbook section, then do the Practise questions.
- Try the **Quick check** without peeking, then open the answers.
- Before a test, use the chapter README's **review checklist**.
- Math is written in LaTeX (`$x^2$`), which renders on GitHub and in VS Code's Markdown preview.
