> 📝 **Outline only. This topic is not in the textbook.** It is part of MTH1W, so you'll need class notes or another resource. Use [the section template](../../templates/section-template.md) when writing notes.

## Curriculum expectations

- **F1.2**: identify financial situations that involve appreciation and depreciation, and use associated graphs to answer related questions

## Key ideas to learn

- [ ] **Appreciation:** value goes up over time (e.g. property, collectibles)
- [ ] **Depreciation:** value goes down (e.g. cars, electronics)
- [ ] Read and interpret graphs of value over time; linear vs. non-linear (percent-based) change
- [ ] Example: a car worth 30 000 dollars losing 15% per year is worth $30\,000(0.85)^n$ after $n$ years
