> 📘 **Curriculum:** F1.3 · 📖 **Textbook:** not covered · [⬅ Strand F: Financial Literacy](../)

> 📝 **Outline only. This topic is not in the textbook.** It is part of MTH1W, so you'll need class notes or another resource. Use [the section template](../../templates/section-template.md) when writing notes.

## Curriculum expectations

- **F1.3**: compare the effects that different interest rates, lengths of borrowing time, ways in which interest is calculated, and amounts of down payments have on the overall costs associated with purchasing goods or services, using appropriate tools

## Key ideas to learn

- [ ] **Simple interest:** $I = Prt$
- [ ] **Compound interest:** interest earns interest; $A = P(1 + i)^n$, connected to [powers](../../B-number/02-powers/)
- [ ] How the interest rate, borrowing time, compounding method and **down payment** change the total cost
- [ ] Compare buying outright, financing and leasing using a spreadsheet or online calculator
